# 🏕️ Back to Nature

Eine responsive Webanwendung für einen Camper-Vermietungsservice – übersichtlich, benutzerfreundlich und im naturverbundenen illustrativen Design gestaltet.

## 📋 Über das Projekt

Back to Nature ist die Startseite einer Webanwendung für ein Naturerlebnis mit Campside, welches Camper, Vans, Kastenwägen und Wohnmobile vermietet. Ich nutzte das Übungsprojekt um die praktische Anwendung von Responsive Design in Umsetzung mit verschiedenen Website-Elementen auszuprobieren. Das Ergebnis ist ein intuitives und einladendes Web-Erlebnis, welches sich flexibel verschiedenen Bildschirmgrößen anpasst.


---

## 🛠️ Technologien

- **HTML5** - Strukturierung der Webseiteninhalte
- **CSS3** - Gestaltung und responsives Layout
- **Flexbox** - Flexible und moderne Layouts
- **Media Queries** - Anpassung für verschiedene Bildschirmgrößen
- **Vanilla CSS** - Keine Frameworks oder Preprocessoren

---

## ✨ Features

- ✅ **Responsive Design** - Flexible Anpassung an verschiedene Bildschirmgrößen (Mobile, Tablet, Desktop)
- ✅ **Hero-Sektion mit Filtersuche** - Prominente Startsektion mit Suchfunktion (Design)
- ✅ **USP-Darstellung** - 5 visuelle Boxen mit Icons zur Präsentation der Alleinstellungsmerkmale
- ✅ **Angebotsübersicht** - Beach-, Ocean- und Mountain-Pakete mit passenden Illustrationen und Informationen
- ✅ **Flexbox-Layouts** - Dynamische Anordnung der Inhalte für verschiedene Displaygrößen
- ✅ **Modulare CSS-Struktur** - Separate Stylesheets für verschiedene Geräteklassen
- ✅ **Optimierte Bilddarstellung** - Einsatz von `object-fit: contain` für konsistente Bildgrößen
- ✅ **Barrierefreiheit** - Angepasste Schriftgrößen und Abstände für bessere Lesbarkeit

---

## 📚 Was ich gelernt habe

- **Responsive Design mit Media Queries**: Gezielte Anwendung von `@media only screen and (min-width: 768px)` für verschiedene Breakpoints
- **CSS Flexbox**: Implementierung flexibler Layouts für dynamische Inhaltsanordnung
- **Modulare Dateiorganisation**: Strukturierung von CSS in separate Module für bessere Wartbarkeit
- **Mobile-First Workflow**: Planung und Umsetzung vom kleinsten zum größten Viewport
- **Bildoptimierung**: Verwendung von `object-fit` für konsistente Bilddarstellung über verschiedene Größen
- **Benutzerfreundlichkeit**: Gestaltung einer intuitiven Navigation und klaren Informationsarchitektur
- **Design-Konsistenz**: Umsetzung eines durchgängigen, illustrativen Designkonzepts
